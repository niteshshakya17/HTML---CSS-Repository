Assignment 5 – GitHub Repository Link

Push Steps

1. GitHub Repository

Create a repository on GitHub and give it a suitable name. If the repository already exists, use the existing repository.

2. Push the Local Project to GitHub

Open the terminal in your local project folder and run:

git remote -v
git branch -M main
git push -u origin main

If the remote repository is not configured, add it first:

git remote add origin https://github.com/niteshshakya17/HTML---CSS-Repository.git

3. Verify the Upload

Refresh the GitHub repository page and confirm that all files and commits appear.

Optional: Host It for Free

Open Settings → Pages in the GitHub repository. Select the "main" branch and "/ (root)" folder, then click Save.

The website URL will be:

"https://niteshshakya17.github.io/HTML---CSS-Repository/"

Submission
