Box Model Calculation

Total Width 200 + 40 + 20 = 260px
Total Height 80 + 40 + 20 = 140px

Box Sizing: Border Box

When we use box-sizing: border-box, padding and border are included in the total width and height of the box.

The total width will remain 200px. The content width will become 140px.

The CSS Box Model contains Content, Padding, Border and Margin.
