# what happen between typing a URL and seeing the page

**Instructions:** Paste the URL of any website you visited and write down your understanding of what happens behind the scenes when a user requests that page.

### Website URL Visited:
[https://google.com](https://google.com)

### My Answer:
When a user types a URL into a browser, the following steps occur to display the page:

1. **DNS Lookup:** The browser checks cache and contacts a DNS server to convert the URL into an IP address.
2. **TCP Connection & HTTP Request:** The browser establishes a connection and sends an HTTP request to the server.
3. **Server Response:** The server processes the request and sends back the HTML, CSS, and JavaScript files.
4. **Rendering:** The browser parses these files and paints the final webpage on the screen.
